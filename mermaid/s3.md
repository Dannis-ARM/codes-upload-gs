# Notes
**Data Durability**
In short: Data durability measures the **probability that data will not be lost or corrupted** over a given period.

- 99.999999999% (11 nines) means that, under standard usage, statistically only 1 object would be lost out of 100,000,000,000 objects.
- AWS commitment for S3 Standard: annual probability of data loss ≈ 0.000000001%.
- Data is effectively considered permanently safe.
